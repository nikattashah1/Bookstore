# 📚 BookNook - Online Bookstore

A modern, responsive e-commerce platform for buying books, built with React JS. BookNook offers a curated collection of books across various genres with a seamless shopping experience.

## ✨ Features

### 🛒 **Core Shopping Features**
- **Browse Books**: View 50+ books across 11+ categories
- **Search Functionality**: Search by title, author, or category
- **Category Filtering**: Filter books by genre (Self-Help, Fiction, Business, Kids, etc.)
- **Shopping Cart**: Add/remove items, adjust quantities
- **Responsive Design**: Works on desktop, tablet, and mobile

### 👤 **User Experience**
- **User Authentication**: Login/Register system with form validation
- **Dark Mode**: Toggle between light and dark themes
- **Checkout Process**: Multi-step checkout with order summary
- **Newsletter Subscription**: Email subscription with validation

### 📱 **Modern UI/UX**
- Clean, book-themed design with warm color palette
- Interactive cart dropdown
- Smooth animations and transitions
- Loading states and error handling
- Responsive grid layouts
